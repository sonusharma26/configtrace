# Changelog

## 0.3.0 — source-only update, 2026-09-28

Added bounded provenance DAGs, native env loader observations and early option declarations, configuration contracts, deterministic diagnosis and failure markers, opt-in Worker capture, ordered local history, graph/timeline reports, a structured diagnosis API, and a tools-only read-only MCP server.

Extended schema to configtrace/2 while retaining configtrace/1 input acceptance. Added empty-state evidence, per-context case/Worker metadata, adapter manifests and declarations. Preserved existing v0.2 workflows instead of duplicating them.

Added focused unrun test sources, synthetic native/Worker/boundary fixtures, contract/MCP examples, roadmap status mapping and rewritten documentation. node-config, convict and NestJS runtime adapters remain unimplemented planned catalog entries. No build, type check, test, dependency installation, benchmark or client validation was run. This is not a published or validated release.

This is an unvalidated source implementation. It has not been installed, built, tested, published or deployed. v0.1 is a milestone within this tree, not a separately released package.
