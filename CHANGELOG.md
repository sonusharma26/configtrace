# Changelog

## 0.2.0 — source delivery, 2026-09-22

This is an unvalidated source implementation. It has not been installed, built, tested, published or deployed. v0.1 is a milestone within this tree, not a separately released package.

### v0.1 milestone implemented in source

Direct Node CLI/library launcher; preload and selected-key environment Proxy; startup, read, write, delete and missing-state observations; a contained dotenv adapter; call-site attribution; keyed value representation; versioned artifacts; evidence explanation; paired-run diff; synthetic stale-environment demo; separate application/recorder outcomes.

### v0.2 additions implemented in source

Pattern selectors; optional Node source-map attribution; ordered read-sequence comparisons; coverage/partial-capture reporting; optional bounded asynchronous direct Node children; static HTML evidence and comparison reports; strict export policies and fresh jointly exportable comparison domains; local adapter API; focused test sources, positive/negative fixture corpus and manual validation workflow.

### Deliberate limits

No shell history, native/Worker-wide tracing, browser build-time provenance, production agent, hosted service, automatic fixes or AI dependency. Runtime/loader/OS compatibility remains unverified. See the README, security policy and release checklist before use.
